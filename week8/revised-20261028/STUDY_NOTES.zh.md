# 新版 Week 8 学习笔记：从记忆到 Transformer

这份笔记对应 2026-10-28 的 24 页《Language models and the transformer》。课程把六
部分连成一条线：先把文字变为向量，再用计数与网络预测，理解网络怎样存事实，最后
把注意力与 MLP 组合，并讨论怎样分配训练算力。

## 1. Token 和嵌入：文字如何进入计算

token 是模型处理的基本单位。token id 只是查表索引，编号相近不意味着意思相近。
嵌入（embedding）为每个 token 存一个向量；相似词向量可以在几何上接近。两词关系
可用单位向量之差表示，如果多组词对的差大致平行，说明关系表现为一个共同方向。

本周在现成的 potion-base-8M 表中取三组各九对词。每对与其余八对的平均方向比较，
得到均值 0.466、0.549、0.433；把表的行随机重排后，均值接近 0。这个对照保留向量
本身，却打乱了词和向量的对应关系，因此支持“关系与词义的对应有关”。它不代表词义
可以被单一方向完整描述。

## 2. 自回归与 n-gram：更多上下文为什么不总是更好

自回归模型（autoregressive model）将文本概率写成逐个下一 token 条件概率的乘积。
每一步对有限词表归一化，所以固定长度序列的总概率可以精确归一。交叉熵是正确 token
的平均负对数概率；困惑度（perplexity）是其指数。为了比较不同 tokenizer，还需把
总损失换成 **bits/字符**，而不能直接把不同 tokenizer 的 nats/token 当作同一单位。

1–6 gram 分别依据前 0–5 个 token 的计数预测。未见过的组合会有零概率，add-k 平滑
为每种结果加上相同的伪计数；k 只在训练集尾部的调参段选择，最终再用完整训练集
计数。数据按故事先切分：24,867 个训练故事、2,763 个验证故事，故事间以 EOS 分隔。

本次 1–6 gram 的 bits/字符为 3.403、2.136、1.473、1.310、1.464、1.793。上下文到
4-gram 时效果最好，之后可能的组合太多，真实训练数据覆盖不足；6-gram 验证目标中
约 23.5% 的 n-gram 未在训练中出现。这是估计误差与上下文信息之间的权衡。

## 3. MLP：固定权重中的键值记忆

键值记忆（key–value memory）将查询与每个 key 比较，把对应 value 按相似度加权。
如果其他 key 也有非零相似度，它们的 value 会混进答案。干扰与信号之比 R 是混入部分
的范数除以目标部分的范数；R≈1 表示两者同量级，并不意味着每个像素恰好有一半错误。

外积存储容量随 key 维数 d 近似线性增长。ReLU 抑制负相似度，ReLU²、ReLU³ 进一步
压低小正相似度，使容量分别接近 d²、d³ 的增长。本次拟合的五个斜率为 0.988、
1.003、1.042、1.906、2.767。M>256 时每个随机样本固定检查 256 个存储键，故这些是
声明了抽样范围的估计，而非穷举所有键。

一 token MLP 与 bigram 看见同样多的历史，因此充分训练后应逼近 bigram，而不是凭空
拥有更长上下文。本次验证损失 3.04371，距 bigram 3.03819 仅 0.00552。
扩展分析中，本次隐藏单元的前五 token 激活集中度中位数从初始化 0.137 变为训练后
0.209；PDF 的参考实验观察到相反方向。不同结果应保留，不能把参考数字当成实测。

## 4. 注意力：由当前文本写入的记忆

固定权重存放训练时学到的规律；当前故事刚出现的名字则需要临时上下文。注意力用
每个位置的 query、key、value 构建这类随文本增长的记忆。softmax 把相似度转换成
归一化权重，β=8 时匹配 key 相对普通 key 的权重非常突出。

你指出的图把“算”字的 32×32 像素作为一个 value，与随机图片一起存储。四列分别是
外积、ReLU、ReLU² 和 softmax；行对应 M=64、256、1024、4096。图中的 R 是实际计算
而非从课件抄写：M=4096 时依次为 8.137、5.713、1.209、0.0565。因此 softmax 仍能
清晰回忆，其他几种方法的干扰已达到或超过信号。点面积在每个面板内按回忆值缩放，
颜色表示该次 R 是否小于 1。

## 5. Transformer：结合上下文注意力和 MLP

本周的 block 先 layer norm、因果多头注意力和残差，再 layer norm、GELU MLP 和残差；
位置向量提供顺序。因果掩码使位置 t 的注意力对未来位置恰为零。在一个长度 64 的
输入窗口中，每个位置都预测右移一格的 token，模型一次前向即可学习多个预测。

实际模型两层、宽 96、四头，训练 6,000 步；完整验证得到 1.230 bits/字符，低于
4-gram 的 1.310。温度、top-k、top-p 和 min-p 改变采样分布；top-p 必须保留让累计
概率首次越过阈值的那个 token。固定宽分布上下文上的五次 100,000 次抽样卡方 p 值
均 >0.001，接近零的温度总选最大概率 token。

模型自己在 T=1 采样时，实际 token 的平均惊讶度应与它预测的平均熵一致，差异 z 为
0.186；T=0.7 采样仍按 T=1 模型评分时，z=−78.026。这个检验针对模型自己的分布，
并不说明生成文本都真实或有意义。八个头的图显示注意力指向哪里，不能单凭热图断言
每个头完成什么语义任务。

## 6. Chinchilla：如何分配计算预算

模型规模 N 与训练 token 数 D 在固定算力下相互制约。课程拟合
`L = E + A/N^α + B/D^β`，并用 `C≈6ND` 把两者联系起来。只加大模型而不给它足够
数据，损失可能反而变差。

我们对 240 条保留记录的 log loss 用 Huber 损失拟合，比较 27 个起点，并对数据做
400 次 bootstrap：α=0.347±0.015、β=0.367±0.021，E=1.817±0.025。原论文打印的
参数对这些记录的平均 log 残差约 +0.0167；重新拟合的平均残差约 −0.00066。在指定
预算下最优 D/N 约 17.9，95% bootstrap 区间约 [7.1,36.9]，包含 20。区间来自对所给
记录的重采样，不代表对未来一切模型或训练方式的保证。
