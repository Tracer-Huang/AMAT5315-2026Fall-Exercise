# Week 11 · 难问题、归约与张量网络采样

[课程讲义](https://giggleliu.github.io/AMAT5315-2026Fall/week11-learning-sheet.html)从受挫的 Ising 磁体切入。沿闭环的键偏好相乘若为 −1，至少有一条键无法满足。给定自旋后可以逐键算出能量，但寻找全局最低能量的复杂度取决于图结构。讲义用这个差异引出 P、NP、NP-complete 以及归约。

| 部分 | 讲解 | 实验 |
|---|---|---|
| 1. 复杂度与归约 | 把整数分解转成电路可满足性，再转成自旋玻璃基态问题。一般图的 Ising 能量阈值判定与平面无场例子的复杂度不同。 | 用 pred 对 15、6、7 执行归约、求解、解码与乘积检查。 |
| 2. 用自旋编码逻辑门 | 位映射到 ±1，正确真值行共享最低能量。XOR 需要辅助自旋，组合后的门通过共享变量传递约束。 | 枚举七种门和 AND–NOT–SET1 电路的全部 16 态，标出合法行，画 gates.png。 |
| 3. 精确收缩与抽样 | 玻尔兹曼权重在收缩树上求和得到 Z。用最小能量及其简并度组成的代数做第二套递推。从同一棵树向下按条件权重抽样。 | 检查 10×10 铁磁体。对 factor_15 计算 log Z、最低能量、简并度，抽 2000 态并解码最低能样本。对 k=2…8 比较两种规划器，画 factoring.png。 |
| 4. N 皇后 | 0/1 局部张量以一位 carry 记忆当前线上是否已有皇后。行列恰好一个，斜线至多一个。所有合法棋盘权重都是 1。 | 对 N=4…10 精确计数，对 N=6、8 各抽 200 个棋盘，逐个查冲突并画 nqueens.png。附加检查 N=11、12。 |

## 复现

实测 arm64 macOS 27.0.1、Rust 1.98.1、CMake 4.4.3、Python 3.12.8、pred 0.6.0、omeco 0.2.6。若机器尚未安装 CMake，先执行 `brew install cmake`。

```bash
cd week11
cargo install problemreductions-cli@0.6.0 --locked
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
PYTHON=.venv/bin/python bash reproduce.sh
```

脚本构建 release 版并直接调用 `target/release/tnsample`，也可以用 `cargo install --path . --locked` 安装。绘图与独立核验可单独执行 `.venv/bin/python review.py`。原始数据在 `runs/`，图在 `artifacts/`，两者均由本目录的 Git 忽略规则排除。pred 0.6.0 的 solve 会打印讲义记录的 panic 诊断，实测仍正常返回并给出可核验的结果。

实验采样与格点键使用 seed 2026，磁体逆温度 β=2。greedy 使用 omeco 默认配置。TreeSA 使用 fast 和 time-optimized 评分，试验 RNG 由 omeco 内部管理。规划并列选择可随进程变化，进而改变宽度和同一采样种子对应的轨迹，每次运行保存实际计划树。格点与 pred bundle 的能量符号按讲义分别处理。磁体基态简并度用任意精度整数，JSON 中存为十进制字符串。皇后 carry 网络按行消去，将切面上的列及对角线 carry 压为位掩码，只访问非零转移，保存切面计数供条件采样。N 皇后使用固定行序，支持 N=1…12。

## 审核结果

- [逻辑门和电路](artifacts/gates.png)中，七种门及三门电路的最低能量状态与真值约束逐行一致。
- [整数分解和收缩宽度](artifacts/factoring.png)中，15 解为 3×5，6 解为 2×3。7 的返回候选 1×3 有残差 4。铁磁体得到最低能量 −180、简并度 2。104 自旋的 15 得到 −299、简并度 1、log Z≈598.317945；pred extract 对最低能样本重新给出 3×5。最终复核得到 1442 / 2000 次基态，期望 1455.29（标准差 19.91）。k=2…8 的 greedy 宽度为 5、9、17、19、27、38、54，TreeSA 为 4、7、9、11、13、15、18。
- [皇后计数和采样](artifacts/nqueens.png)中，N=4…10 得 2、10、4、40、92、352、724，与 OEIS A000170 一致。N=11、12 分别是 2680 和 14200。两组各 200 张样本全部通过行列和对角线检查。8 皇后抽到 82 种不同棋盘，一例为 `[3,0,4,7,5,2,6,1]`，按行列出从 0 起算的列。

下次课用三张图串起整个实验。先展示合法逻辑行与能量最低点如何对应，再从 15 的基态比特串解码成 3×5，并用 2000 p₀ 对照直方图。讲清楚 sc 是中间张量条目数的 log₂，讲义中的约 2k+1 对应约 2·4ᵏ 个条目，因此即使比 greedy 窄，成本仍随 k 指数增长。最后展示皇后计数对照及一张样本棋盘。
